# Ponto Público

O **Ponto Público** é um site de utilidade pública que reúne, em um só lugar, consultas de **CEP, DDD, feriados nacionais e municípios brasileiros**.

O projeto foi desenvolvido para a disciplina **Aplicações Frontend**, usando HTML, CSS, JavaScript puro e Bootstrap. As informações são obtidas diretamente das APIs públicas **ViaCEP, BrasilAPI e IBGE**, sem back-end.

**Acesse o site:** https://abreufabio.github.io/ponto-publico/
